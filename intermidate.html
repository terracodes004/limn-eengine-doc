Physics & Gravity

Enable physics on any Component to give it gravity. The engine applies it every frame automatically.

see more... 
const player = new Component(50, 50, "blue", 100, 100, "rect");
display.add(player);

player.physics = true;   // turn on gravity
player.gravity  = 0.4;   // downward pull per frame
player.bounce   = 0.3;   // energy kept on bounce (0–1)

function update() {
    player.hitBottom(); // stops the player at the canvas floor
}

✅ What happens: every frame the engine adds gravity to an internal gravitySpeed value and applies it to speedY. hitBottom() clamps the player at the bottom edge and bounces them.

NOTE: you must call player.hitBottom() inside update() or the player will fall off screen forever.

PropertyPurposeDefault
physicsEnables gravity-based movementfalse
gravityDownward acceleration per frame0
gravitySpeedAccumulated vertical speed from gravity0
bounceEnergy kept on impact (0 = no bounce, 1 = full)0.6

hitBottom() and bounce

hitBottom() keeps a Component from falling through the floor of the canvas and bounces it based on the bounce value.

see more... 
const ball = new Component(30, 30, "red", 200, 0, "rect");
display.add(ball);
ball.physics = true;
ball.gravity = 0.5;
ball.bounce  = 0.7; // bouncy ball

function update() {
    ball.hitBottom();
}

✅ The ball falls, hits the canvas floor, and bounces. Each bounce is 70% of the previous height. Set bounce = 0 for a dead stop.

NOTE: hitBottom() uses the display canvas height as the floor. If you need custom floors use move.hitObject().

MethodPurposeParameters
hitBottom()Clamps to canvas floor and bouncesNone
move.hitObject(id, other)Treats another Component as a floorComponent, floor Component

move.glideX / glideY / glideTo

Smoothly ease a Component to a target position over a set duration using cubic ease-out. No manual lerp needed.

see more... 
const box = new Component(50, 50, "green", 0, 200, "rect");
display.add(box);

// On keypress, glide to x=700 over 2 seconds
window.addEventListener("keydown", () => {
    move.glideX(box, 2000, 700);   // id, duration (ms), target x
    move.glideY(box, 2000, 400);   // id, duration (ms), target y

    // Or both axes at once:
    move.glideTo(box, 2000, 700, 400); // id, ms, x, y
});

✅ The Component eases smoothly using cubic ease-out — fast at the start, slowing as it approaches the target. Perfect for UI animations, cutscenes, and enemy patterns.

MethodPurposeParameters
move.glideX()Ease to target X over durationid, duration ms, target x
move.glideY()Ease to target Y over durationid, duration ms, target y
move.glideTo()Ease both axes simultaneouslyid, duration ms, x, y

move.project – Projectile Motion

Launch a Component as a real physics projectile — give it an angle and velocity and the engine handles the arc.

see more... 
const ball = new Component(20, 20, "orange", 100, 500, "rect");
display.add(ball);

window.addEventListener("dblclick", () => {
    // move.project(id, velocity, angle°, gravity, ground)
    move.project(ball, 10, 45, 0.3);
    // Launches at 45° upward with gravity pulling it down
    // Bounces on the canvas floor automatically
});

✅ The angle is in degrees. 0° goes right, 90° goes straight up. Gravity is how fast it pulls down each frame. The ball bounces on the floor using the Component's bounce value.

NOTE: You can pass a custom ground height as the 5th parameter e.g. move.project(ball, 10, 45, 0.3, 400)

ParameterPurposeExample
velocityLaunch speed10
angleLaunch direction in degrees45
gravityDownward pull per frame0.3
groundY position of floor (optional)display.canvas.height

Camera Follow & Smooth Follow

The camera can lock onto any Component and follow it — either instantly or with smooth lerped movement.

see more... 
const player = new Component(40, 40, "blue", 400, 300, "rect");
display.add(player);

function update() {
    // Move player with keys
    if (display.keys[39]) player.speedX =  4;
    if (display.keys[37]) player.speedX = -4;
    if (display.keys[40]) player.speedY =  4;
    if (display.keys[38]) player.speedY = -4;

    // Instant camera lock
    display.camera.follow(player);

    // Smooth follow (recommended)
    display.camera.follow(player, true);
}

✅ With smooth follow the camera eases behind the player using lerp — it feels natural and professional. Without it the camera snaps to the player exactly each frame.

NOTE: Set display.camera.worldWidth and worldHeight to prevent the camera going beyond your world boundaries.

Method / PropertyPurposeDefault
camera.follow(target, smooth)Follow a Componentsmooth = false
camera.worldWidthMax world width for clamping1000
camera.worldHeightMax world height for clamping1000

Camera Zoom with setZoom()

Scale the entire canvas view in or out. Call it every frame inside update() to maintain the zoom level.

see more... 
function update() {
    display.camera.follow(player, true);

    // Zoom in to 150%
    display.camera.setZoom(1.5);

    // Zoom out to 80%
    display.camera.setZoom(0.8);

    // Normal (no zoom)
    display.camera.setZoom(1.0);
}

✅ Values above 1 zoom in, values below 1 zoom out. Call it every frame — if you stop calling it the zoom resets. Great for menus, cutscenes, or dramatic moments.

MethodPurposeParameter
camera.setZoom(amount)Scale the canvas viewnumber (1.0 = normal)

Sprite Animation

The Sprite class animates a spritesheet — all frames in one horizontal image. Use AnimatedSprite for named animation states like "run", "jump", "idle".

see more... 
// Basic Sprite
// Sprite(imageSrc, frameWidth, frameHeight, frameCount, frameSpeed, x, y)
const hero = new Sprite("hero.png", 64, 64, 8, 6, 100, 200);
display.add(hero);

function update() {
    hero.update(); // advance the animation
}

// ── Named animations with AnimatedSprite ──
const fighter = new AnimatedSprite("fighter.png", 64, 64, 200, 300);
fighter.addAnimation("idle",  0, 3,  8, true);
fighter.addAnimation("run",   4, 11, 5, true);
fighter.addAnimation("jump", 12, 15, 4, false);
display.add(fighter);

function update() {
    if (display.keys[39]) fighter.playAnimation("run");
    else                   fighter.playAnimation("idle");
    fighter.updateAnimation();
}

✅ addAnimation(name, startFrame, endFrame, speed, loop) defines a named clip. playAnimation(name) switches to it without restarting if it's already playing.

MethodPurposeParameters
addAnimation()Define a named frame rangename, start, end, speed, loop
playAnimation()Switch to a named animationname
updateAnimation()Advance the animation — call in update()None

TileMap Basics

Build grid-based levels with a 2D number array and tile Component templates. 0 means empty, 1+ means a tile type.

see more... 
const display = new Display();
display.start(800, 600);

// Define tile templates (index 0 = tile type 1, index 1 = tile type 2)
display.tile = [
    new Component(64, 64, "green",  0, 0), // grass
    new Component(64, 64, "#8B4513", 0, 0), // dirt
];

// 0 = empty, 1 = grass, 2 = dirt
display.map = [
    [0, 0, 1, 1, 1, 0],
    [1, 1, 1, 2, 1, 1],
    [2, 2, 2, 2, 2, 2],
];

display.tileMap();        // build the map
display.tileFace.show();  // render it

// Collision with tiles
function update() {
    if (display.tileFace.crashWith(player)) {
        // player hit a tile
    }
}

✅ Each number in the map array corresponds to a tile template at that index (minus 1). The engine places them at the correct grid positions automatically.

NOTE: Tile types start at 1 in the map array but at index 0 in the tile array.

Property / MethodPurpose
display.map2D array defining the level layout
display.mapWidthWidth of the Tilemap
display.mapHeightHeight of the Tilemap
display.tileArray of Component tile templates
display.tileMap()Build the TileMap from map + tile
display.tileFace.show()Render all tiles
display.tileFace.crashWith(obj)Collision check against all tiles

Tctxt – Styled Text UI

Tctxt is an upgraded text Component with background fill, padding, alignment, and baseline control — perfect for score displays, dialogue boxes, and HUDs.

const scoreText = new Tctxt(

move.accelerate & decelerate

Add acceleration to a Component's speed and decelerate it smoothly back to zero — great for vehicle-style or slippery movement.

see more... 
const car = new Component(60, 30, "yellow", 100, 300, "rect");
display.add(car);

function update() {
    if (display.keys[39]) {
        // accelerate right, max speed 8
        move.accelerate(car, 0.5, 0, 8, 0);
    } else {
        // decelerate when key is released
        move.decelerate(car, 0.3, 0);
    }
    move.bound(car);
}

✅ accelerate() adds to the current speed each frame, clamped to a max. decelerate() subtracts from speed without overshooting zero — the Component glides to a stop naturally.

MethodParametersPurpose
move.accelerate()id, accelX, accelY, maxX, maxYAdd acceleration up to max speed
move.decelerate()id, decelX, decelYReduce speed toward zero smoothly

Platform Game Tutorial

Put everything together — physics, jumping, camera follow, and a tilemap floor.

see more... 
<!DOCTYPE html>
<html>
<head><title>Platform Game</title></head>
<body>
<script src="epic.js"></script>
<script>
const display = new Display();
display.start(800, 400);
display.backgroundColor("#1a1a2e");

const player = new Component(36, 48, "blue", 100, 100, "rect");
player.physics = true;
player.gravity  = 0.5;
player.bounce   = 0.05;
display.add(player);

const floor = new Component(800, 20, "#555", 0, 380, "rect");
display.add(floor);

const scoreText = new Tctxt("20px","Arial","white",12,30,"left",false,"alphabetic","rgba(0,0,0,0.5)",10,4);
scoreText.setText("Score: 0");
display.add(scoreText);

let score = 0;

function update() {
    // Movement
    if (display.keys[39] || display.keys[68]) move.accelerate(player, 0.6, 0, 6, 0);
    else if (display.keys[37] || display.keys[65]) move.accelerate(player, -0.6, 0, 6, 0);
    else move.decelerate(player, 0.4, 0);

    // Jump
    if ((display.keys[38] || display.keys[87]) && player.gravitySpeed >= 0) {
        player.gravitySpeed = -10;
    }

    player.hitBottom();
    move.hitObject(player, floor);
    move.bound(player);
    display.camera.follow(player, true);

    score++;
    scoreText.setText("Score: " + Math.floor(score/60));
    scoreText.fixed();
}
</script>
</body>
</html>

✅ Arrow keys or WASD to move. Up/W to jump. The camera follows the player. Score counts up every second.
