ParticleSystem

Spawn, configure, and auto-clean particles. Must call ps.update() every frame.

see more... 
const ps = new ParticleSystem(display);
MethodParametersPurpose
emit(x,y,opts)x, y, options objectSpawn one particle
burst(x,y,count,opts)x, y, count, optionsSpawn many at once
createEmitter(x,y,opts)x, y, optionsContinuous emitter — returns emitter object
update()—Advance all particles — call every frame
clear()—Remove all particles and emitters

Particle options: life, speedX, speedY, randomSpeed, gravity, friction, alphaFade, scale, scaleFade, rotationSpeed, color, colors, randomColor, width, height, type ("rect"/"circle"/"image")

Presets via move.particles: explosion, smoke, sparkle, rain, blood, magic
