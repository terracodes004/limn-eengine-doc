Scene Management

Assign Components to scenes to manage game states — main menu, gameplay, game over — without creating and destroying objects.

see more... 
const display = new Display();
display.start(800, 600);

// Scene 0 — main menu
const menuBtn = new Component(160, 50, "white", 320, 270, "rect");
display.add(menuBtn, 0);  // second param = scene number

// Scene 1 — gameplay
const player = new Component(40, 40, "blue", 100, 100, "rect");
display.add(player, 1);

// Scene 2 — game over screen
const gameOverText = new Component(200, 50, "red", 300, 250, "rect");
display.add(gameOverText, 2);

function update() {
    if (display.scene === 0) {
        // show menu, wait for click
        if (display.x && menuBtn.clicked()) {
            display.scene = 1; // switch to game
        }
    }
    if (display.scene === 1) {
        // gameplay logic here
        if (playerDead) display.scene = 2;
    }
}

✅ Only Components whose scene number matches display.scene are drawn and updated. Switch scenes instantly with display.scene = n.

NOTE: Components default to scene 0 if you don't pass a scene number to display.add().

FeatureHow to use
display.add(obj, scene)Register Component to a scene number
display.sceneSet to switch the active scene

Particle System Basics

The ParticleSystem lets you spawn, configure, and auto-clean individual particles. Always call ps.update() inside your game loop.

see more... 
const display = new Display();
display.start(800, 600);

const ps = new ParticleSystem(display);

function update() {
    ps.update(); // REQUIRED — advances and removes dead particles

    // Spawn one particle at mouse position
    if (display.x) {
        ps.emit(display.x, display.y, {
            width: 6, height: 6,
            color: "#ffaa00",
            life: 40,
            speedX: (Math.random()-0.5)*4,
            speedY: -2,
            gravity: 0.1,
            friction: 0.97,
            alphaFade: 0.025,
            type: "circle"
        });
    }
}

✅ emit() spawns one particle. Dead particles (life=0 or alpha=0) are removed automatically by ps.update().

OptionPurposeDefault
lifeFrames until the particle dies60
alphaFadeHow fast it fades per frame0.02
frictionSpeed multiplier per frame (drag)0.98
type"rect", "circle", or "image""rect"
randomColorPick random color from colors[]false

Built-in Particle Presets

Six ready-made effects via move.particles.*. One line of code for professional visual feedback.

see more... 
const ps = new ParticleSystem(display);

function update() {
    ps.update();

    if (enemyDied) {
        move.particles.explosion(ps, enemy.x, enemy.y, 40); // intensity=40
        move.particles.blood(ps, enemy.x, enemy.y, 20);     // amount=20
    }
    if (playerPowerUp) {
        move.particles.magic(ps, player.x, player.y);
        move.particles.sparkle(ps, player.x, player.y);
    }
    // Continuous weather
    move.particles.rain(ps, 0, 0, 3);    // intensity per frame
    move.particles.smoke(ps, 200, 300);  // one puff per call
}

Continuous Emitters

An emitter fires particles automatically every frame at a set rate. Start, stop, and reposition it at any time.

see more... 
const ps = new ParticleSystem(display);

// Create emitter at position 400,300 firing 20 particles/sec
const fire = ps.createEmitter(400, 300, {
    rate: 20,
    randomSpread: true,
    speed: 2,
    color: "#ff4400",
    life: 35,
    alphaFade: 0.03,
    gravity: -0.05,
    type: "circle"
});

function update() {
    ps.update();

    // Move emitter to follow player
    fire.setPosition(player.x + 20, player.y);

    // Toggle with key
    if (display.keys[70]) fire.stop();  // F key
    else fire.start();
}

✅ createEmitter() returns an emitter object with start(), stop(), and setPosition(x,y). The rate is particles per second, scaled automatically to your frame rate.

MethodPurpose
fire.start()Begin emitting particles
fire.stop()Pause emission (particles already out survive)
fire.setPosition(x,y)Move the emitter's origin

Circle Collision

Enable radius-based collision for more accurate detection on round objects like balls, coins, and characters.

see more... 
const ball   = new Component(40, 40, "blue",   200, 200, "rect");
const target = new Component(40, 40, "red",    350, 200, "rect");
display.add(ball);
display.add(target);

// Enable circle collision (radius auto = half of largest dimension)
ball.enableCircleCollision();
target.enableCircleCollision(25); // custom radius

function update() {
    if (ball.crashWithCircle(target)) {
        target.setColor("yellow"); // hit!
    } else {
        target.setColor("red");
    }
}

✅ crashWithCircle() uses distance between centres vs sum of radii. Falls back to AABB if the other object doesn't have circle collision enabled.

MethodPurposeParameter
enableCircleCollision(radius)Enable circle collisionoptional radius (auto if omitted)
crashWithCircle(other)Check circle overlapAnother Component

Camera Shake

Apply a brief positional jolt to the camera — perfect for explosions, hits, and impacts. It auto-resets after ~42ms.

see more... 
function update() {
    if (explosion) {
        // Shake the main display camera
        display.camera.shake(10, 8);  // x offset, y offset

        // If using perform() mode, shake the fake canvas too
        fake.camera.shake(-10, -8);
    }
}

✅ The shake offsets the camera by the given amount then resets after 1/24th of a second. For stronger effect combine it with rotation shake.

NOTE: In perform() mode both cameras need to be shaken — display.camera and fake.camera.

MethodParametersPurpose
camera.shake(x, y)x offset, y offsetBrief position shake

Camera Rotation Shake

Rotate the entire canvas briefly for a dramatic twist effect — great for big impacts, boss hits, or screen-crack moments.

see more... 
window.addEventListener("dblclick", () => {
    // Rotation shake — angle in radians (~5–10 degrees works well)
    display.camera.shakeRotation(0.08);

    // Combine with position shake for maximum impact
    display.camera.shake(12, 10);
    display.camera.shakeRotation(0.1);
});

✅ 0.1 radians ≈ 5.7 degrees. Both shakes reset automatically. Combine them for a camera-twist-and-slam effect on big hits.

MethodParametersPurpose
camera.shakeRotation(angle)angle in radiansBrief rotation shake

Dynamic TileMap Editing

Add and remove tiles at runtime to create destructible environments, growing maps, or puzzle mechanics.

see more... 
display.tileMap();
display.tileFace.show();

// Add a tile at grid position column 3, row 2
display.tileFace.add(1, 3, 2); // tileId, gridX, gridY

// Remove the tile at column 5, row 1
display.tileFace.remove(5, 1); // gridX, gridY

// Get the tile object at a position
const t = display.tileFace.rTile(3, 2);
console.log(t.x, t.y); // world coordinates

// Get all tiles of a type
const grassTiles = display.tileFace.tiles(1); // tileId = 1

✅ add() and remove() update the map array and refresh automatically. Use this for Minecraft-style terrain editing, breakable blocks, or procedural level changes.

move.pointTo & move.circle

Rotate a Component to face a world position, or make it orbit continuously using angle-based movement.

see more... 
const turret = new Component(40, 20, "gray", 400, 300, "rect");
const orbiter = new Component(20, 20, "cyan", 400, 200, "rect");
display.add(turret);
display.add(orbiter);

function update() {
    // Turret always faces the mouse
    move.pointTo(turret, display.x || 0, display.y || 0);

    // Orbiter spins around its own angle
    move.circle(orbiter, 2); // 2 degrees per frame
    orbiter.moveAngle();
}

✅ pointTo() sets the angle so the Component's right side faces the target. circle() increments the angle, and moveAngle() moves along that angle using speedX/speedY.

MethodParametersPurpose
move.pointTo(id,x,y)Component, target x, target yRotate to face a position
move.circle(id,speed)Component, degrees per frameIncrement angle for orbiting
id.moveAngle()—Move along the current angle

Component.fixed() – HUD Anchoring

Keep a Component locked to the screen even when the camera is moving — essential for score displays, health bars, and any UI element.

see more... 
const healthBar = new Component(150, 18, "red", 16, 16, "rect");
display.add(healthBar);

function update() {
    display.camera.follow(player, true);

    // Without fixed() the health bar would scroll with the world
    // With fixed() it stays at screen position (aX, aY) regardless of camera
    healthBar.fixed(); // must call every frame
}

✅ fixed() sets the Component's world position to cancel out the camera offset. Set the initial position with aX and aY (they are stored at construction time from x and y).

NOTE: Call fixed() every frame inside update() — it needs to recalculate as the camera moves.

PropertyPurpose
aX / aYScreen-space anchor position (set at construction from x, y)
fixed(ctx)Lock to screen position each frame — pass display or fake

const EventBus = {
    listeners: {},
    on(event, callback) {
        if (!this.listeners[event]) this.listeners[event] = [];
        this.listeners[event].push(callback);
    },
    emit(event, data) {
        if (this.listeners[event]) {
            this.listeners[event].forEach(cb => cb(data));
        }
    }
};

const player = new Component(40, 40, "#5b8cff", 700, 500, "rect");

const healthBarBg = new Component(220, 25, "#440000", 20, 50, "rect");

// ===== CUSTOM KNOCKBACK =====
function applyKnockback(target, fromX, fromY, strength = 150) {
    const angle = Math.atan2(target.y - fromY, target.x - fromX);
    target.speedX = Math.cos(angle) * strength;
    target.speedY = Math.sin(angle) * strength;
    target.physics = true;
    setTimeout(() => {
        target.speedX = 0;
        target.speedY = 0;
        target.physics = false;
    }, 200);
}

// ===== UPDATE FUNCTION =====
function update(dt) {
    if (!gameActive) return;
    display.camera.follow(player);
    healthBarBg.fixed()
    healthBarFill.fixed()
    scoreText.fixed()
    particles.update();
    
    // Invincibility frames
    if (invincibleTimer > 0) {
        invincibleTimer -= dt;
        player.alpha = 0.5;
    } else {
        player.alpha = 1;
    }
    
    // Player movement
    let mx = 0, my = 0;
    if (display.keys[37]) mx = -1;
    if (display.keys[39]) mx = 1;
    if (display.keys[38]) my = -1;
    if (display.keys[40]) my = 1;
    
    if (mx !== 0 && my !== 0) {
        mx *= 0.707;
        my *= 0.707;
    }
    
    player.x += mx * 200 * dt;
    player.y += my * 200 * dt;
    
    // Wall collision
    if (tilemap.crashWith(player, 1)) {
        if (mx > 0) player.x -= 10;
        if (mx < 0) player.x += 10;
        if (my > 0) player.y -= 10;
        if (my < 0) player.y += 10;
    }
    
    // Coin collection
    const coins = tilemap.tiles(2);
    for (let coin of coins) {
        if (player.crashWith(coin)) {
            tilemap.remove(coin.tx, coin.ty);
            score += 10;
            scoreText.setText("Score: " + score);
            move.particles.sparkle(particles, coin.x + coin.width/2, coin.y + coin.height/2);
            display.camera.shake(2, 2);
        }
    }
    
    // Enemy AI
    for (let i = 0; i < enemies.length; i++) {
        const enemy = enemies[i];
        
        // Chase player
        if (enemy.x < player.x) enemy.x += enemy.speed * dt;
        if (enemy.x > player.x) enemy.x -= enemy.speed * dt;
        if (enemy.y < player.y) enemy.y += enemy.speed * dt;
        if (enemy.y > player.y) enemy.y -= enemy.speed * dt;
        
        // Enemy collision with player
        if (player.crashWith(enemy) && invincibleTimer <= 0) {
            health -= 15;
            const healthPercent = Math.max(0, health / 100);
            healthBarFill.width = 200 * healthPercent;
            
            applyKnockback(player, enemy.x, enemy.y, 200);
            display.camera.shake(6, 6);
            move.particles.blood(particles, player.x, player.y, 10);
            invincibleTimer = 1.0;
            
            if (health <= 0) {
                gameActive = false;
                const gameOverText = new Tctxt("48px", "Arial", "#ff0000", 400+display.camera.x, 300+display.camera.y, "center");
                gameOverText.setText("GAME OVER - Score: " + score);
                display.add(gameOverText);
            }
        }
        
        // Click to defeat enemy
        if (mouse.down && enemy.clicked()) {
          console.log("uygiik")
            move.particles.explosion(particles, enemy.x, enemy.y, 20);
            score += 50;
            scoreText.setText("Score: " + score);
            display.camera.shake(4, 4);
            enemy.hide();
            enemies.splice(i, 1);
            i--;
        }
    }
    
    // Boundaries
    player.x = Math.max(0, Math.min(1560, player.x));
    player.y = Math.max(0, Math.min(1160, player.y));
}
