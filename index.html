Limn engine

What is Limn engine

Limn Engine is the fourth generation of the TCJSGame project, originally created by Owolabi Kehinde. Starting as JGame in 2023, evolving through TCGame and TCJSGame, Limn Engine represents a complete architectural upgrade — bringing a dual-canvas rendering pipeline, a full particle system, circle collision, scene management, and much more.

see more... It stays true to its roots: no build tools, no complex setup. Just a single .js file and your creativity.

A powerful, beginner-friendly JavaScript 2D game engine for the browser. Built on HTML5 Canvas with a component-based architecture, physics, particles, tilemap support, and a dual-canvas rendering pipeline. Zero‑configuration 2D game engine. One file (epic.js). No npm, no build tools — just HTML + JavaScript. Without Limn, you'd need to manually manage canvas drawing, game loop, input handling, and collision. Limn does everything for you.

📖 Without an engine: You would have to manually draw pixels, handle keyboard events, manage the game loop, and write collision detection. Limn does all of that for you.

Your First Game – Setup

Create an HTML file that includes epic.js. Write the following code – you will see a red square in the centre of a black canvas.

see more... 
              
<!DOCTYPE html>
<html>
<head><title>My Limn Game</title></head>
<body>
<script src="epic.js"></script>
<script>
const display = new Display();
display.perform();
display.start(800, 600);

const player = new Component(50, 50, "red", 400, 300, "rect");
display.add(player);

function update(deltaTime) {
    // Game logic will go here
}
</script>
</body>
</html>

✅ What happens: start() creates an 800×600 canvas, attaches it to the page, and starts the game loop. The red square appears because display.add(player) tells the engine to draw it every frame.
