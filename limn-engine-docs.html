Limn Engine

A powerful, beginner-friendly JavaScript 2D game engine for the browser. Built on HTML5 Canvas with a component-based architecture, physics, particles, tilemap support, and a dual-canvas rendering pipeline.

// 01 · introduction

What is Limn Engine?

Limn Engine is the fourth generation of the TCJSGame project, originally created by Owolabi Kehinde. Starting as JGame in 2023, evolving through TCGame and TCJSGame, Limn Engine represents a complete architectural upgrade — bringing a dual-canvas rendering pipeline, a full particle system, circle collision, scene management, and much more.

It stays true to its roots: no build tools, no complex setup. Just a single .js file and your creativity.

💡 Limn Engine scales with you. Start at Level 1 drawing shapes and reading keys, and grow all the way to Level 4 where you're customising the dual-canvas pipeline and squeezing maximum fps.
// 02 · skill levels

Skill Levels

Limn Engine is structured into four progressive skill levels. Every section in these docs is tagged so you always know what you're ready for.

Level 1

Beginner

You're writing your first game. You know basic JavaScript — variables, functions, if-statements. Limn Engine gives you instant visual results without boilerplate.

  • Create a Display and start it
  • Draw shapes with Component
  • Read keyboard & mouse input
  • Move things with speedX / speedY
  • Detect collisions with crashWith()
  • Play sounds with Sound
Level 2

Intermediate

You've built a game or two. You're comfortable with objects and loops. Now you'll add polish — physics, animations, gliding, and camera work.

  • Enable physics & gravity
  • Use move.glide* & move.project
  • Follow a target with Camera
  • Animate sprites with Sprite
  • Build levels with TileMap
  • Use Tctxt for styled text UI
Level 3

Advanced

You're building complete games with multiple systems. You understand architecture and want your game to feel polished and responsive.

  • Scene management for levels
  • Particle systems & emitters
  • Circle collision detection
  • Camera shake & zoom
  • Accelerate / decelerate patterns
  • Dynamic tilemap editing at runtime
Level 4

10x

You understand the engine's internals. You're optimising render loops, compositing canvases, batching draws, and pushing browser limits.

  • Dual-canvas pipeline (perform mode)
  • Offscreen fake canvas buffer
  • deltaTime-based movement
  • requestAnimationFrame mastery
  • Custom particle systems from scratch
  • Engine extension & patching
// 03 · changelog

What's New in Limn Engine

Everything that makes Limn Engine a leap over TCJSGame v3:

⚡

Dual-Canvas Renderer

A hidden fake canvas handles static content. The main display composites it with dynamic objects — boosting performance via display.perform().

✦

Particle System

Full ParticleSystem with emit, burst, and continuous emitters. Six built-in presets: explosion, smoke, sparkle, rain, blood, and magic.

◎

Camera Shake

Positional shake via camera.shake() and rotational shake via camera.shakeRotation().

⊙

Circle Collision

Enable radius-based collision with enableCircleCollision() and detect via crashWithCircle().

▣

Scene Management

Assign components to numbered scenes. Switch the active level instantly via display.scene.

T

Tctxt — Rich Text

Background fill, padding, alignment, stroke/fill mode, and baseline control — a major upgrade over basic text.

🎨

Canvas Gradients

Linear and radial gradient backgrounds via lgradient() and rgradient().

⬛

setImage / setColor

Swap a component between image and color mode at runtime. Error-safe — falls back to red rect on broken images.

// 04 · setup

Getting Started

Include limn-engine.js, create a Display, and define update() — that's it.

HTML · Minimal Setup  Level 1
<script src="limn-engine.js"></script>
<script>
  const display = new Display();
  display.start(800, 600);

  const player = new Component(40, 40, "#7fffb2", 100, 100);
  display.add(player);

  function update() {
    if (display.keys[39]) player.speedX = 3;
    if (display.keys[37]) player.speedX = -3;
  }
</script>
ℹ️ Level 4 tip: For high object counts (tilemaps, particles), call display.perform() before display.start() to activate the dual-canvas pipeline.

Catch the Box — mouse-click collision
const display = new Display();
display.start(480, 270);
display.backgroundColor("#111");

const box = new Component(40, 40, "#7fffb2", 200, 100);
display.add(box);

let score = 0;

function update() {
  // Move box randomly every 60 frames
  if (display.frameNo % 60 === 0) {
    box.x = Math.random() * 440;
    box.y = Math.random() * 230;
  }
  // Click detection
  if (display.x && box.clicked()) {
    score++;
    console.log("Score:", score);
  }
}

Platform Game — gravity, jump, camera follow
const display = new Display();
display.start(800, 400);

const player = new Component(32, 48, "#5b8cff", 100, 100);
player.physics = true;
player.gravity  = 0.4;
player.bounce   = 0.1;
display.add(player);

const floor = new Component(800, 20, "#444", 0, 380);
display.add(floor);

function update() {
  player.hitBottom();
  if (display.keys[39]) player.speedX =  4;
  if (display.keys[37]) player.speedX = -4;
  if (display.keys[38] && player.gravitySpeed >= 0) {
    player.gravitySpeed = -9; // jump
  }
  move.decelerate(player, 0.4, 0);
  display.camera.follow(player, true);
}

Click-to-explode — particles + camera shake

function update() {

Dual-canvas pipeline — perform mode + deltaTime movement
const display = new Display();

// Activate dual-canvas BEFORE start()
display.perform();
display.start(1280, 720);

// Add 500 static tiles to the fake (offscreen) canvas
const tileset = [];
for (let i = 0; i < 500; i++) {
  const t = new Component(32, 32, "#333", (i%40)*32, Math.floor(i/40)*32);
  fake.add(t); // renders to offscreen buffer
}

// Dynamic player on main canvas
const player = new Component(36, 36, "#7fffb2", 200, 200);
display.add(player);

const SPEED = 200; // pixels per second

function update(dt) {
  // deltaTime-based movement: frame-rate independent
  if (display.keys[39]) player.x += SPEED * dt;
  if (display.keys[37]) player.x -= SPEED * dt;
  display.camera.follow(player, true);
  // fake canvas camera must sync too
  fake.camera.x = display.camera.x;
  fake.camera.y = display.camera.y;
}
Custom continuous rain emitter + performance cleanup
const display = new Display();
display.start(800, 600);
const ps = new ParticleSystem(display);

// Continuous emitter: 80 raindrops/sec across the sky
const rain = ps.createEmitter(0, 0, {
  rate: 80,
  randomOffset: 800,
  width: 2, height: 10,
  color: "rgba(150,200,255,0.5)",
  life: 55, speedY: 8, speedX: 1,
  gravity: 0, friction: 1, alphaFade: 0.015,
  type: "rect"
});

function update() {
  ps.update(); // dead particles auto-removed

  // Pause rain on key press
  if (display.keys[32]) rain.stop();
  else rain.start();
}

Migration from TCJSGame v3

Limn Engine is largely backwards compatible. Here's what changed:

⚠️ The internal component array is now comm (two m's). If you directly referenced com before, update your code.
TCJSGame v3Limn Engine v4Notes
setInterval game looprequestAnimationFrame via ani()Smoother, synced to screen refresh
Single canvas renderingDual-canvas via display.perform()Optional — standard mode still works
No particle systemParticleSystem + 6 presetsNew in v4 L3
AABB collision onlyAABB + circle collisionenableCircleCollision() L3
No camera shakecamera.shake() + shakeRotation()New in v4 L3
Basic text via ComponentTctxt — rich text componentBackwards compatible L2
No runtime image swapsetImage() / setColor()New in v4 L2
camera.follow(target)camera.follow(target, smooth)Added smooth/lerp mode
No gradient backgroundslgradient() / rgradient()New in v4 L2
No scene systemdisplay.scene + display.add(obj, scene)New in v4 L3
